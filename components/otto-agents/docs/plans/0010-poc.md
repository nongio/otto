# 0010: Proof of concept

**Status:** In progress

## Goal

Prove the whole path end to end: type a request in Otto's launcher, have Claude work
on it through otto-agents, and list the resulting sessions from a terminal. Each part is
built well enough to extend later, but covers only what the POC needs.

| Part | Scope for the POC | Deferred to |
|---|---|---|
| **Server** | Sessions with one chat each; `serverSeq` sequencing and broadcast to subscribers; `createSession`, `subscribe`, `listSessions`; `dispatchAction` for `chat/turnStarted`, `chat/turnCancelled` and queued `chat/pendingMessageSet`; `root/sessionAdded` and `root/sessionSummaryChanged` | Reconnect and replay, `disposeSession`, multi-chat, steering messages, other client actions ([0002](0002-core-protocol-loop.md)) |
| **ACP → Claude** | One `claude-agent-acp` process per session; agent message chunks become markdown response parts plus deltas; thought chunks become reasoning; `stopReason` ends the turn; cancel | Tool call state, AHP confirmations, Enter, persistence, resume ([0003](0003-acp-agent-backend.md)) |
| **Launcher → ask** | `otto-launcher --ask` on branch `launcher-ask` in `../otto-4`; Return hands the typed text to otto-agents as a new session in `$HOME` on the default agent, then closes | Folder and agent pickers, error display in the card, notifications ([0007](0007-otto-desktop-integration.md)) |
| **Terminal list** | `otto-agents sessions` prints status, agent, age, folder and title | Opening sessions ([0011](0011-launcher-ask-v2.md)) |

## Decisions

- **Permissions are a per-agent policy.** Nothing in the POC can answer a permission
  prompt: the launcher closes, and the CLI only lists. Each agent therefore sets
  `permissions = "deny"` (the default) or `"allow"`, and the service answers ACP
  permission requests itself. Every decision is logged. AHP confirmations replace this
  in 0003.
- **The launcher queues its request.** A turn can only start once the session is
  ready, and starting Claude takes seconds, so the launcher must not wait for it.
  - The launcher creates the session, then dispatches `chat/pendingMessageSet` with
    kind `queued`. A `ping` round-trip confirms the service has the message, and then
    the launcher exits.
  - The service starts the queued message as soon as the chat can take a turn, using
    the two steps the chat spec prescribes: `chat/pendingMessageRemoved`, then
    `chat/turnStarted` with `queuedMessageId`.
- **Config** is `[[agents]]` in `/etc/otto/agents.toml` then
  `~/.config/otto/agents.toml`, or in the file given with `--config`. Each entry has `id`, `name`, `description`, `command`, `args`, `env`, an
  optional `model` (set on each new session with ACP `session/set_config_option`) and
  `permissions`. With no config, one built-in agent is used: `claude`, running
  `npx -y @agentclientprotocol/claude-agent-acp@latest`
  ([0004](0004-agent-configuration.md) subset).
- **No authentication yet.** The server listens on loopback only.
  [0005](0005-authentication.md) must land before otto-agents listens anywhere else.
- **Backend trait.** The session host drives agents through a small backend interface:
  - Commands in: prompt, cancel.
  - Events out: ready, creation failed, message and thought chunks, turn ended.

  The echo backend (`serve --echo`, and tests) and the ACP backend both implement it.
- **State stays consistent by construction.** Every mutation goes through
  `ahp::reducers`, the same reducers clients run, under one lock that also assigns
  `serverSeq` and enqueues outbound messages.

## Demo

```sh
# terminal 1: the service (reads ~/.config/otto/agents.toml, or runs Claude by default)
cargo run -p otto-agents -- serve

# in Otto (built from ../otto-4, branch launcher-ask)
otto-launcher --ask          # type a request, press Return

# terminal 2: follow it
cargo run -p otto-agents -- sessions
```

To try it without Otto:

```sh
cargo run -p otto-agents --example ask -- --queue "summarise the README"
```

To bind ask mode to a key, add this to Otto's config:

```toml
"Ctrl+Alt+Space" = { run = { cmd = "otto-launcher", args = ["--ask"] } }
```
